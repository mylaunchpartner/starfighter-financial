# Starfighter Financial website

Source for starfighterfinancial.com, which runs as one Custom Code element in GoHighLevel. Made and maintained by My Launch Partner.

| File | What it is |
|---|---|
| `embed.html` | The whole site (styles, markup, scripts) as a GHL code-block embed |
| `version.json` | Bump `v` after any change so live pages pick it up |
| `loader.js` | Called by the GHL snippet; swaps in the latest `embed.html` when the version changes |
| `GHL-SNIPPET.md` | What sits in GHL and when to re-paste it |

Open items on the site: the footer still says "Address to be added", and the merchant quotes are placeholders (see the comment above the testimonials).
